# File Structure

```
navier_stokes/
├── index.html            The page: canvas, controls, settings and feedback panels
├── css/style.css         All styling (dark glass overlay, responsive down to phones)
├── js/
│   ├── gl.js             WebGL 2 helpers: context, programs, float render targets, passes
│   ├── shaders.js        All GLSL: staggered-grid solver passes, multigrid, display, pool
│   ├── scenes.js         The five examples, as GLSL hooks plus tuned constants
│   ├── fluid.js          Incompressible Navier–Stokes solver (scenes 1–4)
│   ├── pool.js           Shallow-water solver (scene 5)
│   ├── ui.js             Settings, scene picker, equations card, feedback, keyboard
│   └── main.js           Frame loop, pointer input, scene switching, URL options, self-test
├── tests/
│   └── browser.mjs       Headless-Chrome runner: self-test and README screenshots
├── docs/
│   ├── INSTRUCTIONS.md   Setup, run, use, test
│   ├── SYSTEM-DESIGN.md  Architecture, flows, decisions, testing, limits
│   ├── FILE-STRUCTURE.md This file
│   └── images/           scene-1.png … scene-5.png (generated by tests/browser.mjs)
├── README.md             One line, screenshots, links
└── navier_stokes.md      Project brief, open questions and changelog
```

## Where to change things

| To… | Edit |
|---|---|
| Add or tweak an example | `js/scenes.js`: copy a scene object and change its hooks and constants |
| Change the solver | `js/shaders.js` (passes) and `js/fluid.js` (pass order, multigrid) |
| Change the look of water or rocks | The `DISPLAY` and `POOL_DISPLAY` shaders in `js/shaders.js`, plus each scene's `background` / `solid` / `decor` hooks |
| Add a setting | `DEFAULTS` in `js/ui.js`, a control with `data-key` in `index.html`, then read it from `settings` |
| Add a self-test check | `selftest()` in `js/main.js` |
